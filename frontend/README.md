# MTS Incident Command — Frontend

React + Vite интерфейс оперативного центра мониторинга и управления инцидентами МТС.

## Особенности
- Точное воспроизведение дизайна Figma (стилистика МТС, темная и светлая темы, шрифты Inter, акцентный фирменный красный `#e30611`)
- Подключение к бэкенду по SSE (`/api/incidents/stream`) для мгновенного обновления интерфейса при изменении `incidents.json`
- Обратный отсчет SLA в реальном времени с цветовой индикацией критичности
- Интерактивная боковая шторка (Drawer) с AI-анализом, хронологией и деталями инцидента
- Поиск по ID, сервису, компоненту и описанию (горячая клавиша `⌘K` / `Ctrl+K`)
- Фильтрация «Все инциденты» / «Моя команда» и канбан-колонки

## Сборка и разработка

```bash
# Режим разработки
npm run dev

# Сборка в backend/dashboard (для прямой раздачи FastAPI)
npm run build
```
