# Incident Generator

Демонстрационный генератор случайных инцидентов для тестирования API и live-дашборда.

Работает на **чистом Python 3.9+** — никаких зависимостей, кроме стандартной библиотеки.

Генератор входит в API под аккаунтом координатора. По умолчанию используется
логин `coordinator`, пароль запрашивается скрытым вводом. Для запуска без
терминала задайте `MTS_COORDINATOR_LOGIN` и `MTS_COORDINATOR_PASSWORD`.
Режим `--dry-run` работает без авторизации.

## Быстрый старт

```bash
# Один инцидент с выводом в консоль
python generator.py

# 10 инцидентов, по одному в 2 секунды
python generator.py --count 10 --interval 2

# Непрерывный поток (Ctrl+C для остановки), каждые 5 секунд
python generator.py --count 0 --interval 5

# Просмотреть сгенерированный JSON без отправки
python generator.py --dry-run

# Указать адрес сервера
python generator.py --url http://my-server:8000 --count 5 --interval 1
```

## Параметры

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--url` | `http://localhost:8000` | Базовый адрес бэкенда |
| `--login` | `coordinator` или `MTS_COORDINATOR_LOGIN` | Логин координатора |
| `--count` | `1` | Количество инцидентов (0 = бесконечно) |
| `--interval` | `0` | Пауза между запросами (секунды) |
| `--dry-run` | выкл. | Вывод JSON без отправки |

## Что генерируется

- **Случайный ID** инцидента формата `INC<15 цифр>`
- **Случайный статус**: Assigned / WorkInProgress / Resolved / Closed / Research
- **Случайный приоритет**: Низкий (30%), Средний (40%), Высокий (20%), Наивысший (10%)
- **Deadline** автоматически рассчитывается от приоритета (1 / 4 / 8 / 24 часа)
- **Продукты, команды, сервисы** — реалистичный набор значений из экосистемы МТС
